# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/sarah-tahoorah/portfolio.git

cd portfolio
```

---

## Install Dependencies

```bash
npm install
```

---

## Start Development Server

```bash
npm start
```

The application will be available at:

```
http://localhost:3000
```

---

## Build for Production

```bash
npm run build
```
